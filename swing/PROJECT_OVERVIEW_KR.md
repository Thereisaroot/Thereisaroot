# WebSwing 프로젝트 개요 (KOR)

이 프로젝트는 HTML5 Canvas 기반의 2D 캐주얼 게임으로, 도형 캐릭터가 점프하여 앞의 로프 끝을 잡아가며 전진합니다. 로프 스윙, 점프·캐치 판정, 아이템 상자, 상점/레벨업(경험치), 통화(돈) 수집 등 핵심 메커닉을 포함합니다.

- 실행 방법: 브라우저에서 `index.html`을 열면 바로 실행됩니다. (번들/서버 불필요)
- 디버그 패널: `V` 키로 표시/숨김. 슬라이더로 물리/스폰 파라미터를 실시간 조정할 수 있으며 `localStorage`에 유지됩니다.

## 구성 파일
- `index.html`: 캔버스와 폰트 로딩, 디버그 패널 DOM, `src/main.js` 로딩
- `style.css`: 배경/캔버스/디버그 패널 스타일
- `src/main.js`: 게임 전 로직(상태, 물리, 스폰, 렌더, 상점 UI 등) 단일 파일 구현
- `deploy.sh`: 외부 경로로 동기화 및 캐시버스터 적용, git 커밋/푸시 스크립트 (로컬 환경 경로에 의존)
- ESLint 설정: `eslint.config.js`, `.eslintrc.json`

## 기술 스택
- 런타임: 브라우저(HTML5 Canvas 2D)
- 언어: 바닐라 JavaScript (모듈/번들러 없음)
- 저장: `localStorage` (튜닝, 저장금액, 최고점수, 경험치, 상점 인벤토리)
- 폰트: Google Fonts `Press Start 2P`

## 게임 루프와 상태
- 고정 타임스텝: `dt = 1/120`으로 업데이트, `requestAnimationFrame` 렌더
- 주요 상태(`State.current`):
  - `intro`: 타이틀/가이드, 클릭 또는 Space로 시작
  - `run`: 실제 플레이(스윙/점프/캐치/아이템/카메라/스코어)
  - `gameover`: 결과/레벨업 안내, 재시작 또는 상점 이동(레벨 2 이상)
  - `shop`: 상점 UI(구매/설명/스크롤/확인 모달)

## 핵심 상수/튜닝(CONFIG)
- 화면/물리: `width/height`, `gravity`, `jumpImpulse`, `baseVx`, 공중 저항 등
- 로프: 길이 범위 `Lmin/Lmax`, 각도/각속도 파라미터, 간격 `Dmin/Dmax`, 짧은 로프 확률/계수, 가장자리 스폰 지터
- 캐치 반경: `catchBase` (고정), 필요 시 일시 확장(아이템)
- 카메라 추적: 부착/자유 상태별 스무딩 속도
- 스타(피버) 모드: 지속시간/고정 로프 길이/촘촘한 간격 등 별도 세트
- 디버그 튜닝(슬라이더): `TUNING_KEY`로 저장/로드, `applyTuningToConfig()`로 `CONFIG` 반영

## 엔티티 구조
- `Rope`
  - 속성: `anchorX/Y`, `L`(길이), `A`(진폭), `omega`(각속도), `phi`(위상), `breakAt`(예정 스냅 시각), `isWebRope`
  - 메서드: `theta(t)`, `tip(t)`(팁 위치/속도/각도 반환)
- `Player`
  - 속성: 위치/속도/각도, `mode`(`attached`|`free`), 현재 로프, 시각 효과 스케일
  - 동작: 부착 시 로프 팁을 추종, 자유 시 중력/감쇠, `airFlap()`로 공중 점프
- `boxes`(아이템 상자)
  - 종류: `extraJump`(+1 점프), `wideCatch`(캐치 반경 임시 +R50), `bigSize`(몸 크기 1.5배), `star`(피버 모드 시작)
- `particles`(효과)
  - `burst/sparkle/shard/text/combo/snap/break` 등 다양한 시각 효과
- `camera`
  - X만 추적, 플레이어를 화면 왼쪽 22% 지점 부근에 유지

## 조작/입력
- 클릭/터치/Space: 입력 발생
  - 부착 상태에서 입력: 로프에서 이탈(점프). 스윙 팁 속도/방향 + `baseVx` + `jumpImpulse` 조합으로 초기 속도 부여
  - 자유 상태에서 입력: 남은 공중 점프 수(`airJumpsLeft`)가 있으면 `airFlap()` 수행
- 롱프레스: `fly` 아이템 보유, 자유 상태, 공중 점프 소진 후에만 발동. 길이(`flyMaxHold`) 동안 상승/전진 유지
- 디버그 패널: `V` 토글(패널 상 인터랙션은 게임 입력 차단)

## 로프 스폰/버퍼링
- `planNextRope()`
  - 현재 팁 위치/예상 점프 궤적을 추정하여, 다음 로프가 화면 우측 가장자리 부근에 ‘닿을 수 있는’ 시점에 팁이 오도록 파라미터(A, L, omega, phi, anchorX)를 탐색
  - 짧은 로프/간격 섞기(`shortLChance`, `DshortMin/Dmin`), 간격/길이 지터로 변주
  - 스타 모드일 때는 고정 길이/좁은 간격/완화된 허용오차로 촘촘히 배치
- `ensureRopesBuffered()`
  - 가장 오른쪽 일반 로프가 목표 가장자리보다 뒤면 새 로프를 연속 배치(스타 모드일 때는 추가 버퍼)
  - 레벨/확률 조건 충족 시 로프 사이에 아이템 상자 스폰
- `cleanupRopes()`
  - 카메라 뒤 먼 로프/상자 정리

## 캐치/스코어/콤보
- 캐치 판정: ‘팁 전용’ 원거리(`catchBase` 또는 임시 증가 반경) 내 진입 시 부착
- 스코어 증가: 이번 이탈 후 사용한 공중 점프 수에 따라 3/2/1점(0/1/2회)
- 콤보: 점프 미사용 캐치(또는 스타 모드 캐치)를 연속하면 콤보 텍스트 효과
- 로프 스냅: EXP≥10부터 확률적으로 부착 중 스냅 예고/발생. 스냅 시 강제 이탈(추가 점수/콤보 없음)

## 카메라/렌더
- 카메라: 상태별 추적 속도로 `camera.x` 보간
- 렌더 순서: 배경 → 로프 → 상자 → 플레이어 → 파티클 → HUD(점수/베스트/저축/레벨, 피버 타이머, 보류 아이템 표기)
- 캐릭터 외형(레벨 기반):
  - LV1: 흰색 원형(‘알’)
  - LV2+: 3레벨 단위로 다각형 변형(삼각/사각/오각…), 내부 색 스트라이프 세그먼트 최대 3
  - 상점 효과: `glow`(글로우), `buds`(꼬리 구슬; 변 개수만큼 배치), `big`(크기 5%씩 증가)

## 상점/레벨/통화 시스템
- 저장 키: `SAVINGS_KEY`(돈), `EXP_KEY`, `BEST_SCORE_KEY`, `SHOP_INV_KEY`, `DEMO_DONE_KEY`
- 레벨: `LEVEL_THRESHOLDS = [10,50,100,200,...,1000]`
- 수익/경험치: 게임오버 시 이번 점수에서 5를 뺀 값 만큼 `$`와 `EXP` 획득(음수면 0)
  - `gamble` 활성 시 다음 1회 수익 1.5배 후 소모
- 상점 아이템(`SHOP_ITEMS`):
  - `glow`(단일, LV≥2): 외곽 글로우
  - `buds`(레벨형, 가격 10, LV≥2): 현재 몸체 변 개수만큼 레벨 상한, 레벨마다 꼬리 구슬 추가
  - `plusjump`(단일, LV≥2): 공중 점프 +1
  - `fly`(단일, LV≥2): 롱프레스 비행 1회/런
  - `big`(레벨형, LV≥5): 가격 20→30→40…(구매 레벨에 따라 +10씩), 상한=현재 레벨
  - `gamble`(단일, LV≥1): 다음 런 수익 1.5배
  - `web`(단일, LV≥1): 긴급 웹샷 1회(로프 즉시 생성/부착, 1회 사용 후 소모)
- 상점 UI: 카드 그리드, 품절/가격 표시, `?` 도움말 팝업(보이는 품목 설명), 구매 확인 모달(YES/NO)

## 아이템 상자/피버(스타)
- EXP≥50 이후, 로프 사이에 확률(`itemSpawnProb`)로 상자 스폰
- 일반 상자: `extraJump`/`wideCatch`/`bigSize` 중 랜덤(획득 시 이펙트/일시 효과)
- 스타 상자: 피버 모드 진입 + 즉시 웹 로프로 부착, 기존 로프/상자 초기화
- 피버 모드:
  - 지속 `starDuration`초, 화면 오버레이/타이머 바 표시
  - 짧은 간격/고정 길이 로프 연속 생성, 캐치 허용오차 완화, 캐치당 3점

## 데모 모드/빠른 모드
- 데모: 최초 실행 시 데모 모드 활성, 일정 금액/EXP/아이템 일부 지급. EXP가 110P 초과되면 다음 게임오버에 저장/EXP/아이템 초기화 후 데모 종료
- 빠른 모드(Fast Mode): 레벨 ≥ 8일 때 게임오버 화면에서 토글. 일부 속도/기획 파라미터(예: 스폰 각속도, 전진 속도 추정)에 1.5배 보정

## 실행 팁
- 시작: Space 또는 클릭
- 가이드: INTRO 화면의 GUIDE 버튼 클릭
- 디버그: `V`로 열고 슬라이더 조정(게임 입력과 분리 처리)
- 재시작: GAME OVER 후 카운트다운(기본 3초) 끝나면 Space/클릭
- 상점: GAME OVER에서 `SHOP` 버튼(레벨 2 이상)

## 코드 진입점/흐름
- `start()` → 저장/폰트/튜닝 로드 → `tick()` 루프 시작
- `tick()` → 누적 시간만큼 `update*`(고정 dt) → `render*` 1회
- 주요 업데이트: `updateIntro`/`updateRun`/`updateGameOver`/`updateShop`
- 주요 렌더: `renderIntro`/`renderRun`/`renderGameOver`/`renderShop`

## 알려진 제약/후속 작업 제안
- 단일 JS 파일 규모가 큼: 모듈 분리(엔티티/상태/상점/UI/이펙트/튜닝 등) 권장
- 밸런싱: 난이도 곡선(간격/길이/스냅/아이템 확률) 지속 조정 필요
- 입력: 모바일 롱프레스/슬라이더 포커스 경계 케이스 점검
- 사운드: 효과음/배경음 추가 지점 마련
- 테스트: 핵심 수학(로프 팁/스폰/캐치) 단위테스트 도입 고려
- 배포: `deploy.sh`는 고정 경로 의존. 환경 변수/설정화 권장

## 빠른 시작(요약)
- 브라우저로 `index.html` 오픈 → Space/클릭으로 시작
- 점프해 로프 팁을 잡아 진행, 5점 초과분만큼 돈/EXP 획득
- GAME OVER → SHOP에서 아이템 구매로 빌드업 → 더 멀리 진행
